## Reproducing Paper Results

The repository contains the scripts, configurations, and data needed to reproduce the quantitative results reported in the paper.

- Table 1: TurtleBot simulation results can be reproduced by following `ua-antfields-demo/README.md`.
- Table 2: UR5e manipulator results can be reproduced by following `manipulator/uncertainty-aware-ntfield/README.md`.
- Appendix tables: additional trial-level results are provided in the appendix.

Generated caches, visualization images, large intermediate logs, and unrelated development artifacts are omitted from the supplemental archive.
